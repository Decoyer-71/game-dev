# refs — 참고 자료 두는 곳 (2026-08-03 신설)

**영상·이미지 원본을 여기 둔다. 저장소에는 안 올라간다**(`.gitignore` 로 제외).

```
refs\
├── video\    ← ⬅ 여기에 영상을 넣는다
└── frames\   ← Claude 가 뽑은 프레임이 여기 쌓인다 (자동 생성)
```

---

## 어떤 확장자로 넣나

**`.mp4` 를 권장한다.** 아래는 전부 처리 가능하다:

| 확장자 | 비고 |
|---|---|
| **`.mp4`** | ✅ **권장.** Windows 화면녹화(`Win`+`G`)·유튜브 다운로드의 기본값 |
| `.mkv` · `.webm` · `.mov` · `.avi` | ✅ 가능 |
| `.gif` | ✅ 가능 (짧은 반복 구간에 좋다) |
| `.png` · `.jpg` | ✅ **가장 쌈** — 변환 없이 바로 읽는다 |

⚠ **정지 화면 몇 컷으로 될 일이면 영상보다 스크린샷이 낫다.** 변환 단계가 없어 즉시 읽고, 화질도 더 좋다.

## 파일 이름

공백 없이, 무엇인지 알 수 있게. 한글도 된다.

```
낭만강호_전투_01.mp4
jianghu_playtest_2026-08-03.mp4
```

⚠ 경로에 **공백을 넣지 말 것** — 작업공간 규율(`../CLAUDE.md` §1). 일부 툴이 공백 경로를 처리하지 못한다.

## 넣은 뒤에 할 일

**파일명과 "무엇을 봐 달라" 를 알려주면 된다.** 예 —

> `refs/video/낭만강호_전투_01.mp4` 넣었어. 전투 한 판이 몇 턴이고 정보를 어떻게 보여주는지 봐줘.

목적을 알아야 어디를 얼마나 촘촘히 뽑을지 정해진다.

---

## ⚠ 미리 알아 둘 한계

- **소리는 못 듣는다.** 프레임(정지 이미지)만 본다. 대사·효과음·BGM 은 분석 대상이 아니다
- **전부는 못 본다.** 10분 영상을 초당 1장만 떠도 600장이다. **구간을 정해 샘플링**한다 — 그래서 목적을 먼저 물어본다
- **빠른 동작은 놓친다.** 이펙트 타이밍처럼 프레임 단위로 봐야 하는 것은 그 구간만 촘촘히 떠야 한다
- **텍스트가 작으면 안 읽힌다.** UI 글자를 읽어야 하면 **720p 이상**으로 녹화할 것

## ⚠ 영상을 커밋하지 않는 이유

`.gitignore` 에 적어 뒀다 — ⓐ **크기**(10분이면 수백 MB. Unity `Library` 1.8GB 를 막아 놓고 영상을 넣으면 앞뒤가 안 맞는다) ⓑ **권리**(참조작 영상은 남의 저작물이다. 사설 저장소라도 재배포에 해당할 수 있다).

→ **분석 결과는 `docs/` 에 글로 남긴다. 커밋되는 것은 그쪽이다.**

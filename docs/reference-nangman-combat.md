**출처**: 사용자가 제공한 플레이 영상 1편 (`refs/video/`, LDPlayer 녹화 · 73.9초 · 1280×732 · 48fps).
⚠ 영상 원본은 **커밋하지 않는다**(`refs/README.md`). 이 문서가 그 영상에서 남는 전부다.

⚠⚠ **표본은 전투 1판이다.** 아래는 그 한 판에서 **실제로 화면에 보인 것**이고, 규칙의 전체 명세가 아니다.
확정과 추정을 구분해 적는다 — `✅ 관측` / `⚠ 추정`.

## 0. 한 문단 요약

**4인 파티가 단일 보스(홍군)를 7경합 만에 잡는다.** 플레이어는 전투 중 아무것도 누르지 않는다 — 모든 무공 슬롯에 **`위탁중`**(자동) 표시가 붙어 있다. 각 인물은 **`집기(集氣)`** 라는 충전형 자원을 매 틱 쌓고, 무공마다 정해진 **필요 집기**가 차면 자동 발동한 뒤 **재사용 대기**에 들어간다. 피격 시 **막기 · 회피** 판정이 뜨고, 회복·상태이상이 별도로 표시된다.

## 1. 전투의 뼈대

| 항목 | ✅ 관측값 |
|---|---|
| 편성 | **아군 4인**(윤신명 · 진무쌍 · 전봉 · 류여의) vs **적 1인**(홍군) |
| 길이 | **7경합 / 약 66초**에 승리 (`승리` 연출 → 보상 화면) |
| 경합당 실시간 | **5~12초 · 평균 약 9초** (1:10s · 2:12s · 3:11s · 4:8s · 5:9s · 6:5s · 7:10s) |
| 경합 상한 | 화면에 **`경합 7 / 99`** — **99경합이 무승부/패배 상한**으로 보인다 ⚠ 추정 |
| 진행 방식 | 인물들이 **제자리에 서 있다가**, 자기 차례에 상대에게 **달려가 치고 돌아온다** |
| 보상 | 경험 1380 · 동전 32냥 · 영력 330. 전투 중 상단에 **`전리품 0`** 이 계속 표시된다 |

⚠⚠ **경합은 실시간 길이가 고정이 아니다.** 연출 시간에 따라 5~12초로 흔들린다 →
**턴제이되 각 행동의 애니메이션이 실시간으로 재생되는 구조**로 보인다. ⚠ 추정.

## 2. ⭐ 자원 — `집기(集氣)`

**이 영상에서 가장 중요한 발견이다.** 우리가 2026-08-02 에 채택한 *부분 충전* 모델과 **같은 계열**이다.

| | ✅ 관측 |
|---|---|
| 표시 | 인물 이름 아래 **칸 나뉜 가로 게이지**(약 10칸). 라벨이 `집기` |
| 충전 | 게이지 옆에 **`+7` · `+6` · `+5`** 가 주기적으로 떠오른다 |
| ⚠⚠ **인물마다 충전량이 다르다** | 윤신명 **+7** · 진무쌍 **+6** · 전봉 **+6** · 류여의 **+6→+5** |
| 충전 주기 | 약 **4~6초마다** 전원이 **동시에** 충전된다 |
| 소비 | 무공이 나가면 **게이지가 0 근처로 리셋**된다 |
| 시작값 | 전투 시작 시 **거의 0** (첫 프레임에서 한 칸) |

### ⚠ 미확정 — 충전 주기가 경합 단위가 아니다

경합 경계는 t=12 · 24 · 35 · 43 · 52 · 57 인데, 충전은 t≈10 · 14 · 19 · 20 … 로 **경합 2 안에서만 3번** 일어났다.
→ **경합당 1회가 아니다.** 실시간 타이머이거나, 경합 안의 개별 행동마다 충전되는 것으로 보인다. **미확정.**

## 3. 무공 슬롯

| | ✅ 관측 |
|---|---|
| 슬롯 수 | 인물당 **3칸** |
| ⭐ **슬롯이 카테고리 고정이다** | **1번 = 공격무공(초식) · 2번 = 내공 · 3번 = 경공** (2026-08-04 **사용자 정정**) |
| **필요 집기** | 아이콘 우상단 **빨간 배지 숫자** — 윤신명 3 · 진무쌍 3 · 전봉 2 · 류여의 3, 2 |
| 발동 조건 | 게이지가 배지 숫자만큼 차면 **자동 발동** (윤신명이 3칸에서 발동하는 것을 확인) |
| **재사용 대기** | 발동 직후 아이콘 위에 **큰 숫자**가 떠서 줄어든다. 윤신명 **8 → 2** |
| 자동 표시 | 모든 아이콘에 **`위탁중`** |
| 무공명 | 발동 시 **말풍선**으로 이름이 뜬다 — `성운일검` · `비화유성` · `추풍축월` · `개천벽지` |

### ⛔ 내가 슬롯 구조를 잘못 읽었다 — **사용자 정정** (2026-08-04)

초안에 *"인당 3칸"* 이라고만 적고 **자유 슬롯처럼 읽었다.** 실제로는 **카테고리 고정**이다.

⚠⚠ **내 반증 논리가 틀렸다.** 리서치가 위키를 근거로 *"초식/내공/경공 각 1개"* 라고 했을 때, 나는 *"류여의의 1·2번 칸이 **둘 다 집기 비용 배지**를 갖고 있으니 둘 다 액티브고, 따라서 카테고리 고정이 아니다"* 라고 반박했다.
→ **틀렸다. 내공은 원래 패시브인데 류여의의 내공이 하필 회복 스킬이라 예외적으로 액티브였을 뿐이다.**
→ 🆕 **일반화: 화면에 보이는 예외 하나로 규칙을 뒤집지 마라.** 표본 1판에서 특수 케이스를 일반 규칙의 반증으로 쓴 것이다. 영상은 *"이 인물이 이렇게 했다"* 만 말하지 *"그것이 보통이다"* 를 말하지 않는다.

### ⚠ 재사용 대기의 단위가 초가 아니다

윤신명의 8 → 2 감소가 **1~4초로 불규칙**했다(t=20 에 8, t=33 에 2). 시간이 아니라
**행동/틱 같은 이산 사건 단위**로 줄어드는 것으로 보인다. **미확정.**

→ **게이팅이 두 겹이다: 자원(집기) + 재사용 대기.** 우리 엔진에는 **두 번째가 없다.**

## 4. 판정 요소

발동 결과가 **글자로 명시**된다. 숫자만 뜨는 것이 아니라 *"무엇이 일어났는지"* 를 말해 준다.

| 표시 | ✅ 관측 | 비고 |
|---|---|---|
| **`막기`** | 흰 굵은 글씨 + 피해 숫자 | **피해가 들어온다**(−302 · −176 · −85). 무효화가 아니라 **경감** |
| **`회피`** | 흰 굵은 글씨, **숫자 없음** | 완전 무효 |
| **`치료`** | 초록 `+853` | 대형 회복 |
| 회복 틱 | 초록 `+55 +60 +53 +102 +98` 이 **여러 명에게 동시에** | 광역 회복 또는 지속 재생 ⚠ 추정 |
| 상태이상 | 이름 아래 **작은 빨간 배지**(`고` · `실` 등) | 아군·적 양쪽에 붙는다 |
| 피해 숫자 색 | 일반 피해는 **빨강**, 막기 시 **주황** | 판정별로 색이 다르다 |

### 마무리 연출

마지막 일격에서 **화면 전체가 흑백 만화풍 컷**으로 바뀌고 큰 피해(−320)가 뜬다.
→ **처치 순간만 연출을 다르게 준다.**

## 5. 체력

- **빨간 가로 막대만 있다. 숫자가 없다.** 인물 이름 바로 아래.
- 반면 **피해 숫자는 크게 뜬다** — 76 · 85 · 176 · 302 · 310 · 320 · 1222 · 1414 · 1717.
- → **절대 체력은 감추고, 한 방의 크기와 남은 비율만 보여준다.**

⚠ 피해 편차가 **20배**(85 ~ 1717)다. 평타와 무공, 막기와 정타의 격차가 아주 크다.

## 7. 이 분석이 우리 설계에 주는 것

### ⭐ 슬롯 제한은 **새 축이 아니라 장착 제한 하나**다 (2026-08-04 정정 후)

카테고리 고정이라는 사실이 이 항목의 성격을 바꿨다. **우리 엔진에 이미 같은 카테고리가 있다** — `ArtKind` 가 `Attack`/`Internal`/`Movement` 로 갈려 있고, **내공·경공은 이미 패시브**다(`SelectArt` 가 `IsSupport()` 를 건너뛴다).

즉 낭만강호식 슬롯을 우리에 옮기면 이렇게 된다:

| | 지금 | 슬롯 제한 후 |
|---|---|---|
| 공격 무공 | 배운 것 **전부** 중 기대 피해 최대를 매 턴 자동 선택 | **1개만 장착.** 그 하나를 쓰거나 평타 |
| 내공 | 배운 것 **전부 합산** | **1개만 장착** |
| 경공 | 배운 것 **전부 합산** | **1개만 장착** |

**⚠⚠ 이것이 `game-research` 가 지목한 최대 위험을 정면으로 없앤다.** 리서치 결론은 *"슬롯을 넣어도 **기대 피해 최대** 자동 선택이 그대로면 슬롯은 장식이 된다"* 였는데, **공격 무공을 1개만 장착하면 고를 것이 아예 없어진다** — 알고리즘의 선택이 사라지고 **플레이어의 사전 선택만 남는다.**

그리고 지금 구조의 병 — *"배울수록 강해지기만 한다"* — 도 같이 사라진다. 보조 무공이 전부 합산되는 지금은 **많이 배우는 것이 언제나 정답**이라 결정이 없다.

⚠ **대가**: 전투 중 무공 다양성이 줄어든다(한 명이 초식 하나만 쓴다). 낭만강호가 실제로 그렇다 — 영상에서 윤신명은 `성운일검`만 반복한다. **그게 나쁜 것인지는 플레이로만 확인된다.**

### ⚠ 재사용 대기는 별개 문제이고, 더 위험하다

쿨다운은 **또 하나의 게이팅 축**이라 기력과 상호작용한다. 어제 쌍(雙)에서 *"대가가 둘이면 어느 쪽으로도 조절할 수 없다"* 를 실측으로 겪었다(`HANDOFF.md` §4-4). `game-research` 도 같은 방향의 통설을 찾았다(Path of Exile 커뮤니티 — *"둘을 같이 쓰면 어느 쪽을 손봐도 다른 쪽이 왜곡된다"*). ⚠ 다만 **1차 개발자 근거는 못 찾았다.**

→ **슬롯과 쿨다운을 한 묶음으로 다루지 않는다.** 슬롯은 싸고 위험이 낮으며 기존 구조에 얹힌다. 쿨다운은 축을 하나 더 만드는 일이다.

**→ 넣기로 한다면 §8 구상안 검토 3단계를 거친다. 판단은 사용자 몫이다.**
